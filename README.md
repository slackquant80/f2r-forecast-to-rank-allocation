# Forecast-to-Rank Allocation (F2R)

Public deployment artifact for the current Forecast-to-Rank Allocation model-portfolio system.

F2R uses point-in-time own-price history across conventional machine-learning models and pretrained time-series intelligence. Their forecasts enter a common cross-asset ranking process before a monthly Top-4 equal-weight portfolio is formed.

The deployed dashboard is generated from a validated public-safe snapshot. It does not fit models, access private local paths, or claim to be an audited brokerage-account record.


Dashboard source is copied from `10_PUBLIC_SYSTEM/dashboard/` at release time; this template intentionally contains no duplicate dashboard source.
